Signed in

This page is a plain landing page. It performs no binding of its own: the registration header is advertised by DbscFilter on authenticated requests, so the offer was already made before this page was rendered.

The login callback response is cross-site — Chromium makes DBSC requests inherit the initiator, and that initiator is the identity provider — so a registration POST issued in response to it would arrive without the SameSite=Lax session cookie.

This page exists because only a navigation the browser issues itself re-originates the request on this site; a server-side redirect does not. From here on, requests carry the session cookie and a registration offer can succeed.
