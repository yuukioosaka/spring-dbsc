You are signed in. Handing over to the DBSC bind step.

This page exists for one reason: the OIDC callback response is cross-site, and Chromium makes DBSC requests inherit the initiator. Returning Secure-Session-Registration straight from the callback would make the registration POST cross-site, so the SameSite=Lax session cookie would be dropped and Chromium would never retry for the rest of the login.

The navigation below is issued by this page, which re-originates the request on this site. /oidc/bind then binds against a session cookie that is actually present.
