1. /app/whoami

The live DBSC report. Answers on a bare login cookie alone, which is exactly what a stolen cookie replays — DBSC does not change that, and this route is here so the difference from a bound session is visible rather than assumed. 




2. /app/payment



    A guarded route: declared with a DbscGuardRoutes matcher, so the guard filter
    refuses it unless the login session's tier is currently dbsc.
    Unbind DBSC in the browser and the same POST answers 403
    DBSC_REQUIRED — a valid login cookie and CSRF token are not enough.











3. DBSC state



    DBSC is driven by the browser on Chromium 145+: the browser POSTs
    /dbsc/regist/<token> on its own after login, using a hardware-backed
    non-extractable key (TPM / Secure Enclave), then keeps it alive with
    /dbsc/refresh. Nothing on this page issues those requests.




    

        This deployment has Soft DBSC enabled. A browser
        without native support loads dbsc-soft-client.js, which does
        the same work with a WebCrypto key in IndexedDB. That key is reachable by page
        script, so it is strictly weaker than the native tier — it still stops a cookie
        stolen from another machine, because the thief has no key to sign with, but not an
        XSS on this origin.

    Soft DBSC is off (dbsc.soft.enabled). No fallback client

    The tier in the report above is what the server enforces right

    refresh that the server refuses drops it back to none rather
    than leaving a stale key in place — press GET /app/whoami after
    a failed refresh to watch the demotion.




    Watch both requests in the DevTools network tab — they are the whole

4. Logging out



    Logout calls dbsc.terminate() before ending the login session,
    so the server tells the browser to forget the binding and clears the binding
    cookie. Without that the device key would outlive the login: the browser
    would keep refreshing a session the app had already ended, and the next login
    would re-couple to a stale key instead of registering a fresh one.
